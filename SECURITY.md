# Security Policy

The best public starting point for Aethel security reviews is now:

- `https://aethel.dev/security`
- `https://aethel.dev/security-policy`
- `https://aethel.dev/compliance`
- `https://aethel.dev/status`
- `https://aethel.dev/docs/procurement-starter-pack`

## Reporting a Vulnerability

Please report suspected vulnerabilities to:

- `security@aethel.dev`

## Initial Response Target

- We aim to acknowledge receipt within `48 hours`.

## Disclosure Guidance

- Please do not disclose vulnerabilities publicly before coordinated review.
- We do not currently advertise a public bug bounty as a formal live program.
- Public acknowledgments, when appropriate, are tracked here:
  - `https://aethel.dev/security-acknowledgments`

## Scope Notes

- The public trust center intentionally distinguishes what is `live`, `partial`, and `planned`.
- If your review also involves buyer diligence, enterprise rollout, procurement, or identity requirements, use the procurement pack and `contact-sales` path after the initial security report.
