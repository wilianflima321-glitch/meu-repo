# UX Market Standard Spine

Generated by `npm run qa:ux-market-standard`. This gate keeps Aethel aligned with the local UX arsenal: mission-first entry, disciplined public chrome, trust-first marketplace, progressive Studio navigation, and no screenshot billboard regressions.

## Market Standards Consulted

| Product | Standard Aethel Must Match | Source |
| --- | --- | --- |
| Linear Agent | Contextual agent work lives where the user already works; chats, comments, skills, and MCP connections stay permission-aware. | https://linear.app/docs/linear-agent |
| Cursor Background Agents | Async agents need visible status, takeover, branch handoff, environment setup, and security disclosure. | https://docs.cursor.com/en/background-agents |
| v0 Platform API | Prompt-to-product should expose clean chat, workflows, project management, deployment, and agent APIs without forcing users through an internal cockpit. | https://v0.app/docs/api/platform/overview |
| Replit Agent | Agent-first creation works best when the user can preview what will be built before committing and see production primitives nearby. | https://replit.com/blog/2025-replit-in-review |
| Unreal Engine 5.6 | High-fidelity game tooling needs production-grade performance, asset organization, animation authoring, and runtime evidence before quality claims. | https://www.unrealengine.com/news/unreal-engine-5-6-is-now-available |
| Adobe Premiere Generative Extend | Creative AI features should state limits, source media constraints, generated-media storage, and cloud requirements inside the workflow. | https://helpx.adobe.com/in/premiere/desktop/edit-projects/edit-with-generative-ai/generative-extend-overview.html |
| Canva Magic Studio | Powerful AI should feel like one place, not a stack of disconnected tools; safety and marketplace trust are part of the creative surface. | https://www.canva.com/en_in/newsroom/news/magic-studio/ |
| Figma Dev Mode | Professional handoff depends on focus views, ready states, annotations, status, and plugins that reduce context switching. | https://help.figma.com/hc/en-us/articles/15023124644247-Guide-to-Dev-Mode |

## Surface Quality Matrix

| Surface | Route | Comparator | Decision | Principle |
| --- | --- | --- | --- | --- |
| Landing | `/` | v0 + Replit prompt-first entry | refine | One mission input, one primary CTA, proof behind progressive disclosure. |
| Auth | `/login, /register` | Vercel + Linear auth | refine | Passkey, magic link, OAuth, and password fallback must be visible without jargon. |
| Pricing | `/pricing` | Linear + Vercel pricing | compress | Three first-choice plans; advanced comparison and policy details stay collapsed. |
| Marketplace | `/marketplace` | Canva app marketplace + browser extension permission review | refine | Default to verified, show permissions/provenance/risk/rollback before mutation. |
| Dashboard | `/dashboard` | Linear home + Replit app creation flow | refine | Answer active project, running agent, cost, approval, and next action in one glance. |
| IDE | `/ide` | Cursor agent sidebar | keep/refine | Agent status, scope locks, replay, cost, and takeover stay visible near the composer. |
| Studio Hub | `/studio` | Unreal project browser + Figma focus views | refine | Show primary surfaces first; deeper editors behind compact progressive navigation. |
| Studio Editors | `/studio/*` | Unreal/Unity editor panes | adapter-needed | Capability, maturity, runtime mode, evidence, and next action before dense editor controls. |
| Cloud Stream | `/studio/cinematic` | Unreal Pixel Streaming operations | held-by-capability | Available only with configured URL, cost, teardown, session, and runtime evidence. |
| Evidence Center | `/evidence` | Figma ready-for-dev + Linear activity context | keep/refine | Proof, blockers, readiness, and next action beat explanatory copy. |
| Admin | `/admin` | AWS/Vercel console IA | hide legacy | Six visible areas; compatibility drawer closed by default. |
| Billing | `/billing` | Stripe/Vercel billing | refine | Spend, limits, and readiness close to the workflow; no accounting wall. |
| Settings | `/settings` | Linear workspace settings | refine | Grouped decisions, current state, and enterprise paths without duplicated navigation. |
| Mobile/PWA | `mobile shell` | Replit mobile + Linear mobile | refine | Review, approve, monitor, and resume; heavy editing remains desktop/local. |

## Policy

- Public pages must show a compact workflow, not decorative proof walls.
- Public chrome is a design-system surface and should not drift into inline styling.
- Marketplace install flows must expose trust, permissions, provenance, and risk before mutation.
- Locale mixing is blocked on the landing spine until i18n owns route-level language selection.
