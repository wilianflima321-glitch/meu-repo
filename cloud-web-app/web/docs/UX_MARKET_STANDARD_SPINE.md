# UX Market Standard Spine

Generated by `npm run qa:ux-market-standard`. This gate keeps Aethel aligned with the local UX arsenal: mission-first entry, disciplined public chrome, trust-first marketplace, progressive Studio navigation, and no screenshot billboard regressions.

## Market Standards Consulted

| Product | Standard Aethel Must Match | Source |
| --- | --- | --- |
| Linear Agent | Contextual agent work lives where the user already works; chats, comments, skills, and MCP connections stay permission-aware. | https://linear.app/docs/linear-agent |
| Cursor Background Agents | Async agents need visible status, takeover, branch handoff, environment setup, and security disclosure. | https://docs.cursor.com/en/background-agents |
| VS Code Workbench | Professional IDEs keep stable regions: Activity Bar, Side Bar, Editor, Panel, and Status Bar; users can hide and reveal depth without losing orientation. | https://code.visualstudio.com/docs/getstarted/userinterface |
| Firebase Studio | Cloud agentic development works when prompt-first prototyping, Code OSS familiarity, previews, emulators, rollback, and cloud deployment are one continuous workspace. | https://firebase.google.com/docs/studio |
| OpenAI Realtime API | Browser voice agents need WebRTC/session state, ephemeral credentials, safety identifiers, tool events, and an obvious interrupt path. | https://platform.openai.com/docs/guides/realtime-webrtc |
| OpenAI Codex App | A premium agent IDE needs parallel long-running tasks, native sandbox boundaries, centralized review, and clear handoff between app, CLI, IDE, and cloud. | https://openai.com/index/introducing-the-codex-app/ |
| Gemini Live API | Live AI interaction needs low-latency audio/video/text, barge-in, tool use, transcripts, and explicit preview/GA capability state. | https://ai.google.dev/gemini-api/docs/live-api/capabilities |
| v0 Platform API | Prompt-to-product should expose clean chat, workflows, project management, deployment, and agent APIs without forcing users through an internal cockpit. | https://v0.app/docs/api/platform/overview |
| Replit Agent | Agent-first creation starts in plain language, refines scope, builds, tests, deploys, and can produce apps, designs, data outputs, files, and connected-service work. | https://docs.replit.com/references/agent/overview |
| Bolt | Prompt-to-build needs one obvious chat entry, instant working preview, hosting/database/domain continuity, and simple agent/model choice without exposing infrastructure first. | https://support.bolt.new/building/intro-bolt |
| Lovable | Natural-language app generation must still preserve real code ownership, GitHub/workspace collaboration, security, enterprise governance, and ongoing operations. | https://docs.lovable.dev/introduction/welcome |
| Manus API | Autonomous agents need persistent identity, task threads, subtasks, message history, polling, and stop/control APIs so long work remains observable and interruptible. | https://open.manus.ai/docs/v2/agents-overview |
| Unreal Editor Interface | High-fidelity creative tooling needs a sovereign viewport, toolbars, outliner/details panels, content organization, and runtime evidence before quality claims. | https://dev.epicgames.com/documentation/unreal-engine/unreal-editor-interface?lang=en-US |
| Adobe Premiere Generative Extend | Creative AI features should state limits, source media constraints, generated-media storage, and cloud requirements inside the workflow. | https://helpx.adobe.com/in/premiere/desktop/edit-projects/edit-with-generative-ai/generative-extend-overview.html |
| Adobe Premiere Timeline | Film tools should keep timeline, source/preview, effects, and generated media review in predictable regions so edits stay inspectable. | https://www.adobe.com/learn/premiere-pro/web/add-frames-generative-extend |
| Canva Magic Studio | Powerful AI should feel like one place, not a stack of disconnected tools; safety and marketplace trust are part of the creative surface. | https://www.canva.com/en_in/newsroom/news/magic-studio/ |
| Figma Dev Mode | Professional handoff depends on focus views, ready states, annotations, status, and plugins that reduce context switching. | https://help.figma.com/hc/en-us/articles/15023124644247-Guide-to-Dev-Mode |

## Competitor Playbook

| Competitor | Pattern to Copy | Aethel Move |
| --- | --- | --- |
| Cursor | Stable IDE shell with agent work adjacent to code, not replacing the workbench. | Keep `ModernIDEShell` canonical and make Agents a right sidecar with receipts/drawers instead of extra cockpit panels. |
| OpenAI Codex | Parallel agents are valuable when tasks have isolated sandboxes, reviewable diffs, durable status, and a clean handoff across app/CLI/cloud. | Promote Agent Ledger, branch/worktree context, approvals, and run evidence into the IDE sidecar without turning the workbench into a telemetry wall. |
| VS Code | Users always know where they are because Activity Bar, Side Bar, Editor, Panel, and Status Bar are consistent. | Treat Aethel IDE as a workbench contract; every new IDE capability must fit one region or stay hidden behind command palette. |
| Firebase Studio | Start from prompt or workspace, then transition into Code OSS, preview, emulator/testing, and deploy. | Keep Dashboard as Firebase-like launchpad and hand off into IDE/Studio with mission context already loaded. |
| Bolt/v0/Replit | A single prompt-first entry is the product; templates and infrastructure are secondary, not first-fold noise. | Do not let landing/dashboard/studio re-expand into card walls; keep one primary input and one next action. |
| Linear | Agent works inside existing work context, respects permissions, keeps history, and turns good conversations into reusable skills. | Use Aethel roles/context packs as reusable skills with explicit permissions, task history, and handoff evidence. |
| Manus | Long-running agents are valuable when tasks, subtasks, messages, stop controls, and outputs are queryable. | Expose Agent Ledger, subtasks, browser replay, cost, and stop/takeover controls as first-class evidence rather than buried telemetry. |
| Figma | Deep tools feel calm because properties and code appear only in context or focus view. | Viewport/Studio editors should show object details, asset quality, and timeline only when the mode/selection requires it. |
| Gemini Live | Live AI feels natural when camera/screen context, mute/interrupt, transcript, and modality state are obvious but not verbose. | Keep copilot live mode as a compact conversation lane with barge-in, transcript, tool-use governance, and model/cost state behind a calm header. |
| Unreal | The viewport is the center of gravity; panels support it rather than compete with it. | Make `AethelViewport3D` the only 3D center and route all scene editors through `CanonicalPreviewSurface`. |
| Lovable | Natural language generation still needs real code, GitHub ownership, enterprise security, and operations. | Position Aethel as evidence-governed code/workflow ownership, not just generation. |
