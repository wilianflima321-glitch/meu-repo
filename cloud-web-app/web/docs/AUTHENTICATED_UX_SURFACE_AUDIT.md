# Authenticated UX Surface Audit

Status: not captured in this commit.

`npm run qa:authenticated-ux-capture` is deterministic, but it requires:

- a running app at `AUTHENTICATED_UX_BASE_URL` or `NEXT_PUBLIC_APP_URL`
- `JWT_SECRET` set in the shell
- Playwright or `@playwright/test` available in the local install

The harness gate is active and verifies the protected route list, signed JWT injection through cookie `token`, localStorage `aethel-token`, and no auth bypass route. Screenshots generated by the capture command are written to `output/playwright/v22-authenticated/` and are intentionally not versioned.
