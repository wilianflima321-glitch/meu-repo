# Game Production Bible V22

Status: compact planning contract. It is not a long public form and it does not execute heavy generation.

## Why

Users should be able to ask for many kinds of games without being forced into one preset. The AI must still preserve coherence across story, world, characters, gameplay, art, audio, playtest, and release.

## UX Rule

The visible UI should show a compact summary, a few pillars, and the first decision. The deep sections stay available as evidence contracts for agents, not as a wall of text for users.

## Required Pillars

- Story
- World
- Characters
- Gameplay
- Art direction
- Audio
- Playtest
- Release

## Completion Rule

The production bible can unlock agent work, but it cannot mark a game complete. Playability still requires build evidence, playtest replay, performance traces, provenance, rollback, and human review.
