# Editor Runtime Transitive Boundaries

Generated by: `qa:editor-runtime-transitive-boundaries`

## Decision

Studio editors can be deep, but their transitive panels must not look like global shell debt. A panel that is reachable only through a route-level Studio editor stays behind that parent dynamic boundary and is reported as such.

## What is protected

- Connected asset model preview is lazy: `ContentBrowserConnected` loads `ConnectedModelPreview` only when the user opens a model preview.
- Transitive editor panels stay behind their parent Studio route: Rig, Hair, Niagara, Foliage, Cloth, Fluid, Terrain, and Scene simulation helpers carry explicit async boundary evidence.
- No connected asset browser shell can import Three or GLTFLoader statically.

## Market critique

Unreal and Unity hide deep tool weight behind explicit editor contexts. Aethel has to do the same in the browser: route shell first, editor depth second, model/runtime preview only after user intent.
