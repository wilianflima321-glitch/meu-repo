## 3. UI Discipline — deepen, don’t invent (binding)

### 3.1 Forbidden (UI pollution)

| Forbidden | Why |
|-----------|-----|
| New top-level “AAA Render Studio” / “Nanite Lab” / “Ray Trace Hub” routes | Duplicates viewport + settings |
| Extra toggles: Nanite / Lumen / Path Trace / VT as separate marketing switches | Placebo until GF pass |
| Parallel material editors | One Material surface (S1) |
| Second outliner / second console | Virtualize existing |
| New billing pages beyond Usage / Credits / Pricing | Plans Canonical surfaces only |
| Electron + Tauri dual chrome | One desktop shell |

### 3.2 Allowed surfaces only (extend these)

| Existing surface | Engine depth goes here | User sees |
|------------------|------------------------|-----------|
| **Viewport** | Micro-Poly / Radiance / Entropy **as quality tiers** behind Capability Score | One “Fidelity” dropdown: Auto / Performance / Quality / Ultra (gated) |
| **Outliner** | Entity scale, virtualize | Same panel, faster |
| **Inspector** | Material / light / VFX params | Same inspector, richer fields |
| **Material editor (S1)** | Substrate graph compile | Existing route |
| **VFX / Niagara graph** | Must **compile** to GPU (Entropy) | Existing graph — no cosmetic-only |
| **Film / Sequencer** | Export real | Existing Film studio |
| **World / Landscape / Foliage** | S2 tools | Existing editors |
| **Settings → Usage** | AI cost (not render) | Billing only |
| **Settings → Graphics** (or Project Settings) | Capability Score readout + Fidelity | **One** settings section — not a new app |
| **Play / PIE** | GAS + physics IPC | Existing play button |

### 3.3 Fidelity UX contract (single control)

```
Project Settings → Graphics
  Capability Score: 72 (detected)     [read-only]
  Fidelity: [ Auto ▼ ]                Performance | Balanced | Quality | Ultra*
  *Ultra requires score ≥75 + desktop wgpu; else disabled with tooltip

Viewport badge (subtle): Auto · Score 72
```

**No** separate Nanite/Lumen/RT checkboxes in user chrome.  
Internal feature flags for developers/QA only (`?debugGraphics=1` or Tauri devtools).

### 3.4 Naming contract (user-facing)

| Internal / plan name | User-facing string |
|----------------------|--------------------|
| Micro-Poly | “High detail geometry” or hidden under Quality/Ultra |
| Radiance | “Dynamic lighting” / “Global illumination” |
| Entropy | “GPU particles / destruction” |
| Nanite (legacy code ids) | **Never** in UI until GF-MESH-001 pass — then “High detail geometry” |
| Path tracing / HW RT | “Ray-traced GI” only when HW path live + score OK |
