## 1. The Apex Router (Elite selection)

### 1.1 Quality over cheap (binding)

> **No concessions to cut COGS if that sacrifices final quality.**  
> Fusion Auto does **not** mean “pick the cheapest specialist under a low ceiling.”  
> Fusion Auto means: **pick the Apex model for that TaskDomain** that still fits the **billing pool** (Premium vs Fast) and plan entitlements.

| Pool state | What Apex selects | Explicitly forbidden |
|------------|-------------------|----------------------|
| **Premium remaining** | Domain elite closed/frontier: e.g. **Claude Sonnet-class, GPT-4o-class, DeepSeek V3-class** for complex code | Mid/weak “budget chat” as Worker |
| **Premium empty** | **Elite open-weights** with high reasoning + max context (e.g. **Grok-class, Qwen 72B-class**, peers at Arena top for domain) | Nano, flash-lite, “basic,” random free router as product fallback |
| **Hero / Ultra** | Opus / o1-class via wallet/BYOK/PAYG only | Ultra on subscription included |

**LMSYS Chatbot Arena (and successors):** `FusionSpecialistRegistry` must track **top Arena (or Aethel golden-bench) models per TaskDomain**, refreshed on a cadence (≤ monthly). Stale registry → Critic QA fail on router PR.

### 1.2 Domain elite examples (illustrative — registry owns live IDs)

| TaskDomain | Apex preference (Premium path) | Apex fallback (Premium empty → Fast pool) |
|------------|--------------------------------|-------------------------------------------|
| Complex code (TS/Rust/C++) | Sonnet / GPT-4o / DeepSeek V3 | Qwen-72B-class / Grok-class / top open code |
| Shader / WGSL | Same code elite with shader bench win | Top open code + long context |
| Lore / narrative | Top creative Arena for writing | Top open 70B+ creative |
| Extract / structure | Strong structured model (still **elite mid+**, not Nano) | Same class open-weights |
| Critic / plan | Premium elite if any left | Strongest open-weights ≠ Actor family |

### 1.3 Billing honesty (does not weaken Apex)

- Apex open-weights still **debit the Fast pool** (1× weight) unless classified Premium by `model-cost-weights`.  
- If Apex Fast burn is high, UX offers wallet/BYOK — **do not** silently swap to a weak model to “save the month.”  
- Prices ($29 etc.) **unchanged**; JobBudget + spend caps protect the company; **quality floor protects the user**.

### 1.4 Amends Routing v1.1

| v1.1 phrase | v1.2 / Apex law |
|-------------|-----------------|
| “best specialist ≤ cost ceiling” first | **Apex for domain first**; ceiling = **pool + plan entitlement**, not “cheapen quality” |
| Low $/M ceilings as primary rank | Rank = **Arena/bench quality**; cost is filter for **which pool**, not excuse for weak models |
| Flash-class extract OK as “specialist” | Extract may use strong structured models; **never** Nano-branded lane |

**Decision #55** (ban Nano) **stands**. **Decision #57:** Apex-first ranking — approved.

## 2. Zero Amnesia (memory blindagem)

### 2.1 Law

> **The AI is never the owner of project memory.**  
> Memory = Aethel infrastructure: **Yjs (CRDT)** + **J.4 VectorIndex** + **L.14 MultiSurfaceContextPack** (+ Scene slice) + **task-evidence-ledger**.

### 2.2 Mandatory Architecture Laws pack (hard gate)

Before **any** agent may write code, mutate manifest, or apply a patch:

| Required in context | Source |
|---------------------|--------|
| Project **Architecture Laws** (`.aethel/laws.md` or project `ARCHITECTURE.md` / cartography “Laws” node) | Repo cartography |
| Relevant **spec .md** slices for touched domains | VectorIndex + RepoGraphRAG |
| **Repo cartography** summary (owners, forbidden paths, conventions) | L.12 / cartography |
| `MultiSurfaceContextPack` with `tokenCount ≤ tokenBudget` | L.14 |
| `ProjectMemoryDigest` (open Critic rejects, naming) | Ledger + Yjs |

```typescript
export interface ArchitectureLawsGateResult {
  verdict: 'PASS' | 'BLOCK';
  lawsPackId?: string;
  missing: Array<
    | 'laws_md'
    | 'cartography'
    | 'context_pack'
    | 'vector_index_cold'
    | 'pack_over_budget'
  >;
  blockedReason?: 'ARCHITECTURE_CONTEXT_REQUIRED';
}
```

**Fail-closed:** If `verdict === 'BLOCK'`, Nexus shows calm error — **no provider call**, no partial write.  
**Decision #58:** Architecture Laws gate — approved (same severity as L.3 no host PTY / Decision #54 pack).

### 2.3 Read-before-write protocol

1. Classify TaskDomain  
2. Build L.14 pack + **Laws pack**  
3. `ArchitectureLawsGate` PASS  
4. CostGuard reserve  
5. Apex Router select model  
6. Execute → Critic → L.5 → Yjs apply  

Skipping step 2–3 is a **Law XI Critic automatic REJECT** in CI policy scans.
