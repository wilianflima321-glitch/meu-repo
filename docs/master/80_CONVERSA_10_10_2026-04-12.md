2. O Que Precisamos Conversar e Criticar (por Área) para Chegar a 10/10
Vou listar exatamente o que criticar, o que conversar e as ideias/funções/sistemas/micro-interações que faltam. Cada tópico é um ponto de conversa real para nós dois (ou com o time).
2.1 Workbench Shell (o centro — Decision 1)
Crítica atual: ModernIDEShell.tsx é bom tecnicamente, mas parece “VS Code com AI grudado” em vez de “studio shell premium”. Density inconsistente, sem inline reasoning visível.
O que criticar/conversar:

Cmd+K e inline AI estão ausentes → Cursor 3 faz em <200ms. Por que ainda não temos?
Activity rail OK, mas falta hover tooltip com shortcut + drag-and-drop tabs com preview fantasma.
Ideias novas: Command Palette global (Cmd+P) com fuzzy search + @mentions. Botão “Split Editor” escondido que aparece só em hover. Double-click na seam do split reseta tamanho automaticamente.

O que fazer: Refatorar ModernIDEShell.tsx para 100% primitives + adicionar InlineAICompletion.tsx.
2.2 AI Operational Layer (Decision 2 — “chat colado no artefato”)
Crítica atual: AIChatPanelPro é o maior pecado (1766 linhas monolíticas, parece sidebar). Decision 2 ainda violada.
O que criticar/conversar:

Chat não fica colado → usuário perde contexto. Manus e Genspark destroem aqui.
Falta parallel agents + wide research + cost tracking visível.
Micro-interações faltando: Streaming incremental com “thinking…”, hover em mensagem mostra “Apply to editor” com fade-in, voice mode aparece só quando mic detectado.
Botões escondidos: “Parallel Research” atrás de 3 dots; “Voice” só em hover do input.

Ideias novas: @file / @symbol mentions funcionais + context window visual (mostra exatamente o que o AI “vê”). Decompor em 5 módulos pequenos (ChatMessageList, ChatInput, etc.).
2.3 Preview / 3D Viewport (Decision 4)
Crítica atual: CanonicalPreviewSurface existe mas é tratado como panel secundário. Score 4/10.
O que criticar/conversar:

Por que o preview não é o viewport primário como Unreal UE5? Isso é o que mata a sensação de “studio sério”.
Falta gizmos, outliner, text-to-texture real-time (Adobe Firefly).
Micro-interações: Hover em objeto 3D mostra gizmo de escala/rotação; scrub na timeline com preview instantâneo.

Ideias novas: Toolbar intent-based que aparece só em seleção; device frames responsivos.
2.4 Aethel Canvas Mode (infinite canvas code-aware)
Crítica atual: Totalmente inexistente (só prompt no 16_MASTER_FIGMA_PROMPT.md).
O que criticar/conversar:

Sem isso nunca vamos superar Figma MCP + Replit Agent 4.
Micro-interações: Drag de card de código para o canvas com preview fantasma; double-tap zoom inteligente; snap-to-grid automático.
Botões escondidos: “Insert Artifact” aparece em hover do canvas.

Ideias novas: MCP-style bidirecional (AI lê o canvas e gera/edita código).
2.5 Design System Unificado (75 guide)
Crítica atual: Ainda 5/10 — 3 dialetos convivendo (CSS vars + tokens inline + aethel-* legacy).
O que criticar/conversar:

Por que o drift continua acontecendo? (commit recente prova).
Paleta: graphite + blue focus + purple rare accent (definido no 75). Por que ainda usamos neon em alguns lugares?
Micro-interações: 140ms hover, motion-safe para reduced motion.
Organização: Spacing canonico (canonical-spacing.ts já existe) deve ser obrigatório em todo lugar.

O que fazer: Migrar ~40 arquivos (lista exata na 77).
2.6 Onboarding, Collab, Mobile, Admin, Billing
Crítica atual: Onboarding 4/10, collab 3/10, mobile placeholder.
O que criticar/conversar:

Onboarding deve ser <60s com agent demo (Replit style).
Collab precisa de cursors reais + presence indicators (Figma 10/10).
Mobile: deep-link que continua a sessão exata do desktop.
Admin/Billing: ainda legacy — precisa da mesma linguagem visual.

Ideias novas: Audit logs de agents + cost tracking + offline-first (Ollama).
